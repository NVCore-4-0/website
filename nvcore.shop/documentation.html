General Installation

A universal guide to installing NVCore resources on your FiveM server.

The Basics

Most NVCore resources follow the standard FiveM installation pattern:

  1. Claim the resource on Tebex.
  2. Download the folder from your FiveM Keymaster.
  3. Extract the folder into your server's resources directory.
  4. Add ensure [resource_name] to your server.cfg.
# Ensure this is ABOVE any scripts that depend on it
ensure nv-spawneffect
Important: Never rename the folder of an Escrow-protected script. Doing so will break the encryption and prevent the script from starting.

NV-FPS Booster

A premium, high-performance optimization tool.

Free Resource
CFX Escrowed
Zero Idle Usage

Optimization Levels

The FPS Booster provides 5 distinct levels of optimization to suit any hardware configuration:

  • OFF: Standard GTA V settings. Best for high-end PCs.
  • LITE: Minor tweaks to shadows and lighting distances.
  • MEDIUM: Balanced mode. Reduces shadow resolution and particle quality.
  • HIGH: Aggressive LOD (Level of Detail) scaling and occlusion disabling.
  • ULTRA: Maximum performance mode. Disables all non-essential shadows, reduces LOD to minimum, and clears world data.

Advanced Features

Special NV Boost

Our proprietary engine that applies cinematic filters while optimizing CPU-bound draw calls.

Night Performance

Toggles city-wide lighting systems to provide a massive FPS jump during night cycles.

Memory Cleaner

Triggers instant Lua garbage collection to clear stale data from your system cache.

Usage & Commands

The script is fully automated but can be controlled via a premium NUI menu:

/fps - Opens FPS Booster Menu

Requirements

To ensure notifications work correctly, the following dependencies are required:

  • ox_lib: Used for modern notifications and UI elements.

Configuration Preview

You can easily modify the command and notification settings in the shared/config.lua file: 

Config = {}
Config.Command = "fps"
Config.Notifications = {
    Position = "top-right",
    Duration = 3000
}
Config.LodScales = {
    Ultra = 0.4,
    High = 0.8
}

FPS Booster Installation

A complete, step-by-step guide to getting NV-FPS Booster running on your QBX server.

Free Resource
CFX Escrowed

Requirements

  • QBX Core: This script is built specifically for QBX-based servers.
  • ox_lib: Required for the NUI menu and notifications. Make sure it's started before the FPS Booster.
  • A registered FiveM Keymaster account linked to the Discord you purchased with.

Step 1 — Claim the Script

Grab NV-FPS Booster from our store — it's completely free:

  1. Head to the NVCore Tebex Store and add NV-FPS Booster to your cart.
  2. Complete checkout (no payment required for free resources).
  3. Once claimed, the resource is automatically added to your FiveM Keymaster under the account linked at checkout.

Step 2 — Download & Extract

  1. Open your server's txAdmin or FTP client.
  2. Pull the resource from your Keymaster grant, or download it directly from your server's asset list in-game via ensure once whitelisted.
  3. Place the extracted folder into your resources directory — for example resources/[nvcore]/nv-fpsbooster.
Important: Do not rename the resource folder. This is an Escrow-protected script — renaming it will break the license check and it will fail to start.

Step 3 — Add to server.cfg

Add the resource to your server.cfg. Make sure ox_lib is ensured before the FPS Booster:

ensure ox_lib

# NV-FPS Booster
ensure nv-fpsbooster

Step 4 — Configure (Optional)

Open shared/config.lua if you want to change the menu command, notification position, or LOD scaling values:

Config = {}
Config.Command = "fps"
Config.Notifications = {
    Position = "top-right",
    Duration = 3000
}

Leave this file untouched if the defaults work for you — no configuration is required to get the script running.

Step 5 — Restart & Test

  1. Restart your server, or run refresh followed by ensure nv-fpsbooster in your server console.
  2. Join your server and run /fps in chat to open the FPS Booster menu.
  3. Select a Boost Level (Lite, Medium, High, or Ultra) and confirm your FPS counter improves.
Tip: Toggle on Special NV Boost for the best balance of visuals and performance, and enable Night Performance if your server does heavy night-cycle roleplay.

Troubleshooting

  • Menu won't open: Confirm ox_lib is started before nv-fpsbooster in your server.cfg.
  • Script won't start / license error: The resource folder was likely renamed. Re-extract it fresh from your Keymaster without changing the folder name.
  • Still stuck? Open a support ticket on our Discord and our team will help you out.

NV-GPS

Real-time GPS tracking network for Police & EMS.

Free Resource
CFX Escrowed
Live Blips

How It Works

Emergency units use a GPS item (or the /gps command) to open a secure connection panel, enter a callsign, and join the emergency GPS network. Once connected, every unit appears live on the map for the rest of the network with a department-coloured blip that changes with their vehicle.

  • Secure connect UI: Confirm, animated connection steps, and a connected status screen showing department and unit ID.
  • Callsigns: Format X-100 (1–3 letters, hyphen, 1–4 digits). Read from your framework or police script when available, otherwise entered by the player and saved.
  • Auto detection: Works with wasabi_police, p_policejob, pluto and any police/EMS script that uses the framework job. Duty state is respected.
  • Vehicle-aware blips: Separate icons for on foot, car, motorcycle, helicopter, plane and boat, with per-job colours and labels.
  • Frameworks: QBCore, Qbox and ESX. Inventory: ox_inventory or the framework's own inventory.

Commands & Exports

/gps - Opens the GPS connect / disconnect panel (same as using the item)
exports.nv_gps:useGPS()          -- opens the panel (used by the inventory item)
exports.nv_gps:isGpsActive()
exports.nv_gps:isGpsConnected()

GPS Installation

Step-by-step setup, including the gps inventory item for ox_inventory and QBCore.

Free Resource
CFX Escrowed

Requirements

  • Framework: QBCore, Qbox or ESX.
  • ox_lib: Used for notifications. Start it before NV-GPS.
  • Inventory (optional): ox_inventory, qb-inventory or similar. Only needed while Config.RequireItem = true.
  • A FiveM Keymaster account linked to the Discord you claimed with.

Step 1 — Claim & Download

  1. Add NV-GPS to your cart on the NVCore Tebex Store and complete checkout.
  2. Download it from your Keymaster grant and place the folder in your resources directory, for example resources/[nvcore]/nv_gps.
Important: Keep the folder name nv_gps. The script is Escrow-protected and the ox_inventory item export (nv_gps.useGPS) depends on this exact name.

Step 2 — Add the Item (ox_inventory)

Open ox_inventory/data/items.lua and add this entry. This is also the setup for Qbox servers using ox_inventory:

['gps'] = {
    label = 'GPS Tracker',
    weight = 200,
    stack = false,
    close = true,
    description = 'Encrypted GPS tracker for emergency services.',
    client = {
        export = 'nv_gps.useGPS'
    }
},

Then copy the item image to ox_inventory/web/images/gps.png.

Step 3 — Add the Item (QBCore)

Open qb-core/shared/items.lua and add:

gps = {
    name = 'gps',
    label = 'GPS Tracker',
    weight = 200,
    type = 'item',
    image = 'gps.png',
    unique = false,
    useable = true,
    shouldClose = true,
    description = 'Encrypted GPS tracker for emergency services.'
},

Copy the item image to your inventory's image folder, for example qb-inventory/html/images/gps.png. NV-GPS registers the item as usable automatically, so no extra code is needed.

Don't want an item? Set Config.RequireItem = false in config.lua and players can connect with /gps only. If you use a different item name, change Config.ItemName and use the same name in the item entries above.

Step 4 — Add to server.cfg

ensure ox_lib

# NV-GPS
ensure nv_gps

Step 5 — Configure

config.lua is left open so you can edit it:

Config.UpdateInterval = 1000     -- blip update rate (ms)
Config.RequireItem = true        -- require the item to connect
Config.ItemName = 'gps'
Config.ToggleCommand = 'gps'
Config.ShowSelfBlip = true       -- show your own blip with [YOU] tag
Config.AutoDetect = true         -- detect police/EMS jobs automatically
Config.TrackedJobs = { 'police', 'lspd', 'ambulance', 'ems', ... }
Config.JobSettings = {           -- per-job blip label / colour / scale
    ['police'] = { label = 'LSPD', color = 3, scale = 0.85, category = 7, shortRange = false },
}

Using a police script with its own job, duty or callsign logic? Point Config.Custom at its exports (isEmergencyJob, isOnDuty, getCallsign).

Step 6 — Restart & Test

  1. Restart the server (or refresh then ensure nv_gps), and restart your inventory so the new item loads.
  2. Give yourself the item, for example /giveitem [id] gps 1 (admin command varies by framework).
  3. Go on duty as police or EMS, use the item or run /gps, enter a callsign and connect.

Troubleshooting

  • Item does nothing (ox_inventory): The folder isn't named nv_gps, or the export line is missing from the item.
  • "Encrypted for Emergency Services only": The player's job isn't tracked. Add it to Config.TrackedJobs or use Config.Custom.
  • "You must be On-Duty": Go on duty with your police/EMS script first.
  • Still stuck? Open a ticket on our Discord.
